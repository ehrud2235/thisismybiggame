# 구슬치기 (초안)

> 위에서 내려다보는 구슬판. 구슬을 당겼다 놓아 튕기고, 분필 원 안에 세우면 통과. 스테이지를 하나씩 올라가고, 몇 스테이지까지 갔는지로 랭킹을 겨룬다.

agar.io처럼 링크만 열면 바로 하는 웹 킬링타임 게임을 목표로 한다. 지금은 **1스테이지 하나**만 있다. 구슬이 날아가는 속도와 벽에 튕기는 느낌을 먼저 확인하기 위한 초안이다.

## 실행

레포 루트에서:

```
npm start
```

브라우저에서 http://localhost:8080/marble/ 을 연다. 설치할 패키지는 없다.

## 조작

| 입력 | 동작 |
|---|---|
| 판 아무 데나 누르고 뒤로 끌었다 놓기 | 끈 반대 방향으로 발사. 많이 끌수록 세다 |
| Esc · 우클릭 | 조준 취소 |
| `R` | 처음부터 다시 |
| `` ` `` | 물리 튜닝 패널 |
| `M` | 소리 켜기/끄기 |

휴대폰 세로 화면에서는 판이 90° 돌아가서 화면을 채운다. 터치로 똑같이 당겨서 쏜다.

## 1스테이지 규칙

- 구슬 3발. 구슬이 멈춘 자리에서 다음 발을 쏜다 (진짜 구슬치기처럼)
- 모든 구슬이 멈췄을 때 내 구슬이 분필 원에 **조금이라도 걸치면 통과**
- 별 3개
  - ★ 통과
  - ★ 구슬 전체가 원 안에 (판 위의 안쪽 점선 원 안에 구슬 중심이 있으면 된다)
  - ★ 한 발에 끝내기
- 가운데 판자가 직선 경로를 막고 있고, 원 앞에 초록 구슬이 있다. 판자를 돌아가거나 벽에 한 번 튕겨서 들어가야 한다

## 물리

| 값 | 시작값 | 뜻 |
|---|---|---|
| 최대 속도 | 1500 px/s | 끝까지 당겼을 때. 판 가로가 1000px이라 최대로 쏘면 약 2초 동안 구른다 |
| 구름 저항 + 속도 감쇠 | 240 px/s² + 0.55/s | 흙바닥 느낌. 빠를 때는 많이, 느릴 때는 일정하게 깎인다 |
| 판자 반발 | 0.72 | 벽에 맞으면 법선 방향 속도의 72%로 튕긴다 |
| 구슬끼리 반발 | 0.93 | 유리구슬이라 거의 그대로 전달된다 |

전부 시작값이다. 게임 안의 튜닝 패널(`` ` ``)에서 바로 바꿔 보고, 마음에 드는 값을 `src/config.js`에 옮겨 적는다.

시뮬은 120Hz 고정 틱이고, 빠를 때는 서브스텝을 늘려서 벽을 뚫지 않는다. 난수를 쓰지 않아서 같은 샷이면 같은 결과가 나온다. 나중에 랭킹 기록을 검증할 때(샷 입력만 받아서 서버에서 다시 돌려보기) 쓸 수 있다.

## 테스트

```
npm run test:marble
```

1스테이지를 각도 1° × 힘 18단계, 6480발 쏴 보고 다음을 출력한다.

- 결정성 (같은 샷 → 같은 결과)
- 벽 뚫림 · NaN
- 한 번에 통과하는 샷 비율. **스테이지 난이도 지표**로 쓴다. 지금 1스테이지는 약 0.3%

`tools/browsertest.mjs`는 Playwright로 실제 브라우저에서 마우스 조준·발사, 통과 카드, 튜닝 패널, 휴대폰 세로 화면을 돌려 보고 콘솔 에러를 확인한다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/config.js` | 튜닝 값 |
| `src/stages.js` | 스테이지 데이터: 판자, 말뚝, 구슬 위치, 분필 원, 통과 조건 |
| `src/physics.js` | 시뮬: 발사, 구름 마찰, 벽·말뚝·구슬 충돌, 통과 판정, 조준선 예측 |
| `src/render.js` | 캔버스 2D. 시뮬 상태를 받아 그리기만 한다 |
| `src/audio.js` | 효과음 (WebAudio 합성) |
| `src/main.js` | 루프, 당겨서 쏘기 입력, HUD, 결과 카드, 튜닝 패널 |

새 스테이지는 `src/stages.js`에 데이터만 추가하면 된다.

## 다음에 정할 것

- **성장:** 구슬 크기를 키우면 '걸치기'는 쉬워지고 '완전 골인'은 어려워진다. 크기보다는 무게·반발이 다른 구슬(쇠구슬, 고무구슬 등)을 모으는 쪽이 판 설계와 덜 부딪힌다
- **통과 방식:** `goal.need`에 '완전히 넣기'가 이미 있다. 다른 구슬을 원 밖으로 쳐내기, 구덩이 피하기, 움직이는 판자 같은 방식을 스테이지마다 섞을 수 있다
- **난이도 곡선:** 쏠 수 있는 구슬 수, 조준선 길이(`guideTime`), 원 크기, 한 방 통과율로 조절한다
- **랭킹:** 도달 스테이지 + 총 사용 구슬 수. 서버가 필요하다

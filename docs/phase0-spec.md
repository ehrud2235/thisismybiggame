# Phase 0 기획 상세 — 코어 검증

> 담당: 기획 AI · 대상: 개발 AI
> 관련 문서: [design-review.md](design-review.md) · [visual-direction.md](visual-direction.md)

## 0. 이 문서가 답해야 할 질문은 하나

**방 하나에서 물건 하나를 던졌을 때 예상보다 큰 사고가 나고, 플레이어가 "한 번 더"를 누르는가?**

Phase 0는 이 질문 하나만 검증한다. 로그라이트 구조, 업그레이드, 점수, 메뉴는 전부 없다. 여기서 재미가 안 나오면 뒤에 무엇을 붙여도 재미가 안 난다.

아래 수치는 전부 **시작값**이다. 플레이테스트에서 조정하는 게 전제이므로, [§10](#10-실시간-조정-가능해야-하는-값)의 값은 게임을 끄지 않고 바꿀 수 있어야 한다.

## 2. 단위와 방

**단위: 1u = 플레이어 몸 지름.** 모든 수치는 이 단위 기준이다.

- 방 크기: **24u × 13.5u** (16:9), 한 화면, 스크롤 없음
  - 왜: 대시 두세 번이면 가로지르는 크기다. 도망칠 곳은 있지만 숨을 곳은 없다.
- 외벽: 파괴 불가
- 내부 기둥 2~3개: 파괴 불가. 벽 튕기기 각도를 만든다.
- 문 2~3개: 적이 등장하는 곳. 등장 1초 전에 문이 깜빡인다.

### 첫 30초를 보장하는 배치

첫 사고는 운에 맡기지 않는다. **배치 자체가 튜토리얼이다.**

```
┌───────────────────────D───────────────────────┐
│                                               │
│   ▢                 ██              G  O      │
│                                   e    e      │
│        P                              G       │
D                   ██                   e     D
│   ▢                            O              │
│               ▢                        ▢      │
│                                               │
└───────────────────────D───────────────────────┘
 P 플레이어   e 적   G 가스통   O 기름통   ▢ 상자   ██ 기둥   D 문
```

개략도다. 좌표는 개발 AI가 정하되 **아래 관계는 지킨다.**

- 플레이어 바로 옆에 상자 2개가 있다. 시작하자마자 손에 쥘 게 있어야 한다.
- 반대편에는 **적, 가스통, 기름통이 한곳에 몰려 있다.** 어떤 물건이든 그쪽으로 던지면 연쇄가 난다. 조준을 대충 해도 첫 사고는 난다.
- 가운데 기둥이 직선 경로를 일부 막는다. 두 번째 판부터 "기둥에 튕겨서 넣을까?"를 생각하게 만든다.

## 3. 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| **우클릭** | **가져오기**: 가까우면 즉시 집고, 멀면 당겨온다 |
| **좌클릭** | **던지기** |
| Space | 대시 |
| R | 즉시 재시작 |

동사는 가져오기, 던지기, 대시 세 개뿐이다. 더 늘리지 않는다.

### 3.1 가져오기 (우클릭)

"당기기"는 업그레이드가 아니라 기본 능력이다. 물건을 주우러 걸어가는 시간은 전부 재미없는 시간이기 때문이다.

- **대상 선택:** 커서 반경 1.5u 안에서 가장 가까운 물체에 자동으로 붙는다. 선택된 대상은 외곽선으로 표시한다.
- **사거리:** 시야 안이면 무제한이다. 기둥에 가려지면 당길 수 없다.
- **체감 목표:** 방에서 가장 먼 물체도 **0.5초 안에** 손에 들어와야 한다.
- **당기기는 안전하다.** 당겨지는 동안에는 가스통을 포함해 아무것도 터지지 않는다. 경로에 있는 적은 밀쳐내기만 한다(피해 0).
  - 왜: 당기다가 가스통이 터지면 플레이어는 당기기를 두려워하게 되고, 결국 걸어다니게 된다.
- **이미 들고 있을 때 우클릭:** 들고 있던 물건을 발밑에 내려놓고 새 대상을 당긴다.
  - 불붙은 가스통을 발밑에 내려놓으면? 죽는다. 의도된 동작이다.
- **적은 기절 상태일 때만 가져올 수 있다** ([§5](#5-적--돌격병)).

### 3.2 던지기 (좌클릭)

**핵심 규칙: 첫 충돌까지는 결정론적이고, 첫 충돌 이후부터 물리다.**

- 던진 물체는 **첫 충돌까지 직선, 등속으로 날아간다.** 중력, 마찰, 사거리 제한이 없다.
- **첫 충돌 이후부터 물리가 적용된다**(튕김, 미끄러짐, 회전).
- 투척 속도: **28u/s** (방 가로를 1초 안에 건넌다)
- **조준 가이드:** 물건을 들고 있을 때만 보인다. 첫 충돌 지점까지 직선을 긋고, 충돌 지점에 마커를 찍는다.
  - **가스통을 들고 있으면 충돌 지점에 폭발 반경 미리보기 원을 표시한다.**
  - 두 번째 충돌부터는 보여주지 않는다. 그 뒤는 선물이다.

이 규칙이 "예상 밖 결과"와 "내가 만든 결과"를 동시에 성립시킨다. 플레이어는 1단계를 정확히 의도하고, 2단계부터는 놀란다.

### 3.3 대시 (Space)

- 거리 3.5u, 소요 시간 0.15초, 쿨다운 0.8초
- **대시하는 동안 무적이다. 폭발도 포함한다.**
  - 왜: "터뜨리고 대시로 빠져나온다", 그리고 "폭발을 대시로 뚫는다"가 이 게임의 스킬 천장이다.
- 대시는 적을 통과한다. 밀쳐내기는 없다.

## 4. 플레이어

| 항목 | 값 | 이유 |
|---|---|---|
| HP | **3칸** (숫자 아님) | 한 번 맞는 것의 무게가 체감된다 |
| 이동 속도 | 7u/s | 빠르게 |
| 가속 | 최고 속도까지 0.08초, 정지도 즉시 | **세계는 미끄럽고, 플레이어는 정확하다** |
| 피격 후 무적 | 0.8초 | |
| 물건을 들었을 때 | 이동 속도 그대로 | 템포 |
| 한 번에 드는 개수 | 1개 | 관리할 것이 생기면 템포가 죽는다 |

**"세계는 미끄럽고, 플레이어는 정확하다."** 물체와 적은 물리적으로 날아다니지만, 플레이어 조작에는 관성이 거의 없다. 조작까지 미끄러우면 "내가 조작하고 있다"는 감각이 사라지고 모든 결과가 남 탓이 된다.

## 5. 적 — 돌격병

Phase 0의 적은 한 종류다. 적의 1차 속성은 공격 패턴이 아니라 **물체로서의 성질**이다. 돌격병의 물체 성질은 **"기절시키면 탄약이 된다"**이다.

### 행동

- **미인지 상태:** 웨이브가 시작되면 적은 플레이어를 모른다. 이동 속도 30%로 배회한다.
  - 인지로 바뀌는 조건: 첫 투척물이 무언가에 맞는 순간 전원이 인지한다. 웨이브 2부터는 3초가 지나도 인지한다.
  - **웨이브 1은 첫 접촉 전까지 관찰 시간이 무제한이다.** 관찰(느림)에서 실행(빠름)으로 가는 리듬을 여기서 처음 배운다.
- **인지 상태:** 플레이어에게 직진한다. 이동 속도는 3.5u/s(플레이어의 50%).
- **공격:** 1u 안에 들어오면 0.5초 동안 예비동작을 한다(몸이 부풀고 뒤로 젖혀지며 붉어진다). 그다음 1.5u를 짧게 돌진한다. 맞으면 플레이어 HP 1칸.
  - 예비동작은 누가 봐도 알 수 있어야 한다. 피할 수 있는 공격이어야 한다.

### 피격 규칙

| 원인 | 피해 | 추가 효과 |
|---|---|---|
| 물체 직격 | 1 | **기절 1.5초** + 넉백 약 4u |
| 벽에 충돌 (10u/s 이상) | +1 | 짧은 기절 |
| 날아온 적과 충돌 | 양쪽 모두 1 | 양쪽 모두 기절 |
| 폭발 중심부 (반경의 40% 이내) | 3 (즉사) | 강한 넉백 |
| 폭발 외곽 | 2 | 강한 넉백 |
| 불 | 초당 1 | 2초 동안 불이 붙는다 ([§6.3](#63-기름통--반응-물체)) |

- HP: **3**

### 기절하면 탄약

- 기절한 적은 우클릭으로 가져올 수 있다. 들고 있는 동안에는 물체처럼 던질 수 있다(무게 1.2, 상자보다 약간 무겁다).
- 3초 넘게 들고 있으면 적이 깨어나 빠져나간다. 플레이어를 밀쳐내지만 피해는 없다.
- 던져진 적도 충돌 시 피해를 받는다.

**왜 기절 상태에서만 집을 수 있는가:** 처음부터 적을 집을 수 있으면 물체를 쓸 이유가 사라진다. 반대로 이 제한이 있으면 **물체로 기절시키고, 적을 집고, 적을 가스통에 던지는** 3단계 흐름이 자연스럽게 생긴다. 이게 "적을 써먹는다"의 가장 작은 단위다.

### 죽어도 연쇄는 끊기지 않는다

- 죽은 적은 **0.6초 동안 물리 물체로 남아** 날아가면서 계속 부딪힌다. 그 뒤 사라진다.
  - 왜: 죽는 순간 판정이 사라지면 그 자리에서 연쇄가 끊긴다. 날아가는 시체가 가스통을 치는 장면이 이 게임에서 가장 웃긴 장면이다.

## 6. 물체 3종

적은 종류, 명확한 규칙. **같은 조건이면 항상 같은 일이 일어난다.** 물리 결과는 매번 다르지만, 규칙은 절대 변하지 않는다. 로그라이트의 학습은 이 규칙 위에 쌓인다.

### 6.1 상자 — 기본 탄약

| 항목 | 값 |
|---|---|
| 역할 | 안전한 기본값. 규칙을 배우는 물건 |
| 무게 | 1.0 |
| 파괴 | **불가**. 던져도 남아서 다시 쓸 수 있다 |
| 적 직격 | 1 피해 + 기절 + 넉백 |
| 반발 | 중간 (튕겨 나간 상자가 다음 것을 친다) |
| 배치 수 | 5개 (웨이브가 지나도 유지) |

### 6.2 가스통 — 큰 연쇄의 시작점

| 항목 | 값 |
|---|---|
| 무게 | 1.0 |
| 폭발 반경 | **3.5u**. **던지기 전에도 항상 바닥에 원으로 보인다** |
| 배치 수 | 3개. 웨이브마다 3개까지 다시 채운다 |

**폭발 조건 (이 세 가지뿐):**

| 조건 | 결과 |
|---|---|
| 강한 충격 (던진 속도급 충돌, 날아온 적·물체와 충돌) | **즉시 폭발** |
| 다른 폭발 반경 안에 있음 | **0.2초 뒤 폭발** (연쇄) |
| 불에 닿음 | **점화 → 2.5초 뒤 폭발** |

- **연쇄 지연 0.2초의 이유:** 동시에 터지면 큰 폭발 한 번으로 보인다. 0.2초씩 밀려야 **연쇄로 읽힌다.** 플레이어는 폭발이 옮겨가는 걸 눈으로 따라가야 한다.
- **점화 상태:** 깜빡이는 속도가 점점 빨라지고, 쉿 소리가 나고, 반경 원이 맥동한다.
  - 점화된 가스통도 가져와서 던질 수 있다. **2.5초짜리 뜨거운 감자**다. 너무 오래 들고 있으면 손에서 터진다.
- **폭발 효과:**
  - 반경 안의 모든 물체와 적을 바깥쪽으로 강하게 날린다. 날아간 물체는 "던진 것"과 같은 충격으로 판정한다. **이게 연쇄의 동력이다.** 폭발은 주변을 탄약으로 바꿔 사방으로 쏜다.
  - 반경 안의 기름에 불을 붙인다.

**플레이어 폭발 피해:**

| 위치 | 피해 |
|---|---|
| 중심부 (반경의 40% 이내) | **2칸** |
| 외곽 | **1칸** |
| 대시 중 | 0 |

- 반경 표시는 두 겹이다. 안쪽 원을 더 진하게 칠한다.
- 거리가 곧 실력이다. 가까이서 터뜨리면 한 번에 반피가 날아간다.

### 6.3 기름통 — 반응 물체

| 항목 | 값 |
|---|---|
| 역할 | 환경 자체를 바꾼다 |
| 파괴 조건 | 강한 충격 또는 폭발 |
| 파괴 시 | 부서진 자리에 **기름 웅덩이**가 반경 2.5u로 퍼진다. 기름통은 사라진다 |
| 배치 수 | 2개. 웨이브마다 2개까지 다시 채운다 |

던지면 맞은 자리에 기름이 퍼진다. **바닥에 원하는 곳을 칠하는 도구**다.

**기름 웅덩이:**
- 위에 있는 적과 플레이어의 마찰이 1/3이 된다. 넉백 거리가 두 배 이상으로 늘어난다.
  - **기름 위의 적은 멀리 날아간다.** 멀리 날아가면 벽에 박히고, 다른 적과 부딪힌다. "기름을 먼저 깔고, 그다음에 친다"는 셋업이 생긴다.
- 불이 닿으면 **점화되어 4초 동안 불 지대**가 된다. 불은 이어진 기름을 타고 번진다.

**불:**
- 적: 초당 1 피해, 그리고 **2초 동안 불이 붙는다.**
  - **불붙은 적이 다른 기름 위로 지나가면 그 기름에 불이 붙는다.** 불붙은 적은 도망다니면서 불을 옮긴다. 불붙은 적을 가져와서 기름에 던지는 것도 된다.
- 플레이어: 닿으면 1칸 (피격 무적 적용)
- 가스통: 점화된다 (2.5초 뒤 폭발)

### 6.4 상호작용표

Phase 0에서 가능해야 하는 조합 전부다. 물체는 3종이지만 조합은 이만큼 나온다.

| A | B | 결과 |
|---|---|---|
| 상자 | 적 | 기절 → 적을 탄약으로 씀 |
| 상자 | 가스통 | 즉시 폭발 |
| 상자 | 기름통 | 기름 웅덩이 |
| 적 (던짐) | 적 | 둘 다 기절 |
| 적 (던짐) | 가스통 | 즉시 폭발 |
| 적 | 벽 (빠른 속도) | 추가 피해 |
| 폭발 | 가스통 | 0.2초 뒤 연쇄 폭발 |
| 폭발 | 기름 | 불 지대 |
| 폭발 | 모든 물체·적 | 바깥으로 발사 → 2차 충돌 |
| 기름 | 적 | 넉백 두 배 이상 → 벽·적 충돌 |
| 불 | 적 | 불붙은 적 → 이동하며 기름 점화 |
| 불 | 가스통 | 2.5초 뒤 폭발 (뜨거운 감자) |
| 폭발·불 | **플레이어** | **피해. 예외 없음** |

## 7. 웨이브 — 방 하나로 루프를 반복한다

Phase 0에는 런 구조가 없다. 대신 같은 방에서 웨이브를 반복해 **10~20초 루프**와 **5분 자발적 지속**을 테스트한다.

| 웨이브 | 적 수 |
|---|---|
| 1 | 3 (미인지, 관찰 시간 무제한) |
| 2 | 4 |
| 3 | 5 |
| 4 | 6 |
| 5 이후 | 웨이브마다 +1, 최대 8 |

- 웨이브 사이 휴식은 **2초**다.
- 휴식 중에 가스통과 기름통을 다시 채운다. **위에서 떨어져 들어온다**(그림자가 먼저 보이고 쿵 떨어진다).
  - 왜: 소모된 탄약이 돌아와야 루프가 계속된다. 떨어지는 연출은 "새 판이 시작된다"는 신호가 된다.
- 동시에 있는 적은 **최대 8**이다. 10이 넘으면 연쇄가 아니라 학살이 되고, 물리가 읽히지 않는다.

## 8. 죽음과 재시작

자기가 만든 폭발에 죽는 것은 벌이 아니라 **웃음 포인트이자 학습 순간**이다. 그렇게 느껴지도록 설계한다.

1. **사망 순간 0.5초 슬로모션**을 건다. 무엇이 나를 죽였는지 눈으로 보게 하기 위해서다.
2. **사인을 한 줄로 표시한다.** 짧고 건조하게 쓴다. 건조할수록 웃기다.
   - `사인: 네가 던진 가스통`
   - `사인: 네가 붙인 불`
   - `사인: 네가 깔아둔 기름 위에서 미끄러짐`
   - `사인: 돌격병`
3. 도달 웨이브를 표시한다.
4. **아무 키나 누르면 재시작**한다. 사망부터 다시 조작 가능해질 때까지 **2초 이내**여야 한다.

사인 표시가 플레이어를 "억울하다"에서 "ㅋㅋ 내 탓이네"로 옮겨준다. 원인을 아는 죽음은 다시 도전할 이유가 되고, 원인을 모르는 죽음은 게임을 끌 이유가 된다.

## 9. 피드백

전체 원칙: **실제 수치보다 체감이 커야 한다. 단, 상황이 안 보이면 안 된다.** 시각 연출의 상세는 [visual-direction.md](visual-direction.md)에 있다.

### 히트스톱

| 사건 | 정지 시간 |
|---|---|
| 물체 직격 | 0.05초 |
| 벽 충돌 | 0.05초 |
| 적 사망 | 0.04초 |
| 폭발 | 0.08초 (**연쇄 중에는 첫 폭발만**) |
| 플레이어 피격 | 0.1초 |

폭발마다 히트스톱을 걸면 연쇄가 버벅인다. 첫 폭발만 멈추고, 나머지는 흘러가게 둔다.

### 효과음

- 재질마다 충돌음이 다르다. 나무 상자는 둔탁하게, 금속 가스통은 쨍하게, 기름통은 출렁이게.
- **연쇄 폭발음은 터질 때마다 반음씩 올라간다** (1초 안에 이어지는 폭발에 한해).
  - 왜: 연쇄가 **귀로 들린다.** 4연쇄는 음이 올라가는 게 들리고, 눈을 떼고 있어도 "뭔가 커지고 있다"를 알 수 있다.
- 점화된 가스통은 쉿 소리를 내고, 폭발이 가까워질수록 음이 올라간다.

### 슬로모션 (A/B 테스트 토글)

- 폭발 3개 이상이 연쇄되면 마지막 폭발 순간에 0.3초 동안 60% 속도로 느려진다.
- 켜고 끈 상태를 비교해서 테스트한다. 연쇄의 클라이맥스가 더 좋게 읽히는지, 템포를 죽이는지를 확인한다.

## 12. Kill Gate — 테스트 방법

### 대상과 진행

- 이 게임을 **처음 보는 사람 5명**. 게임을 좋아하는 사람 3명, 가볍게 하는 사람 2명.
- 알려주는 건 **조작 키 세 개뿐**이다. 목표도, 물건의 규칙도 설명하지 않는다.
- 옆에서 **말없이** 본다. 도와주지 않는다.

### 기록할 것

| 항목 | 방법 |
|---|---|
| 첫 폭발까지 걸린 시간 | 초 단위 |
| 첫 반응("오", "ㅋㅋ", "뭐야") 시점 | 초 단위 |
| 첫 자기 폭발 사망 시점 | 초 단위 |
| 시키지 않고 계속한 시간 | 분 단위 |
| 재시작 횟수 | 회 |
| 사망부터 다시 누르기까지 걸린 시간 | 초 단위 |

### 끝나고 물어볼 것 (세 개만)

1. "가장 기억에 남는 순간이 뭐야?"
2. **"마지막에 왜 죽었어?"**
3. "더 해보고 싶었던 거 있어?"

2번이 핵심이다. **"내가 너무 가까이서 터뜨려서"**처럼 원인을 말하면 성공이다. **"갑자기 뭔가 터져서 모르겠어"**라고 하면 가독성 실패다.

### 합격 기준

- [ ] 30초 안에 첫 반응이 나온다: **5명 중 4명**
- [ ] 시키지 않았는데 5분 이상 계속한다: **5명 중 3명**
- [ ] 죽은 뒤 "한 번 더"라고 하거나 바로 재시작한다: **5명 중 3명**
- [ ] "왜 죽었어?"에 원인을 말한다: **5명 중 4명**
- [ ] 비주얼 테스트 두 가지를 통과한다 ([visual-direction.md](visual-direction.md) §12)

### 불합격이면 이 순서로 조정한다

1. **조작감.** 이동, 던지기, 당기기 속도
2. **피드백 강도.** 히트스톱, 흔들림, 효과음, 폭발 연출
3. **배치 밀도.** 물체 사이 거리, 적과 위험물 사이 거리
4. **폭발 수치.** 반경, 넉백

**물체나 적을 추가하는 건 조정 수단이 아니다.** 세 개로 재미가 안 나오면 다섯 개로도 안 나온다.

## 14. Phase 0 테스트로 답할 열린 질문

기획 단계에서 정하지 않는다. 플레이테스트 데이터를 보고 정한다.

- 당기기 사거리 무제한이 너무 강한가? 발이 필요 없어지는가?
- 기절한 적만 집을 수 있게 한 제한이 답답한가?
- 폭발 중심부 2칸 피해가 너무 가혹한가? 첫 판 첫 사망이 자기 폭발이면 이탈하는가?
- 웨이브 사이 2초가 짧은가?
- 조준 가이드를 끄면 재미가 늘어나는가, 줄어드는가?

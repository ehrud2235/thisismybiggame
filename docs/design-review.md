# 기획 검토서 v1

> 담당: 기획 AI · 대상: 개발 AI, 기획 담당
> 관련 문서: [phase0-spec.md](phase0-spec.md) · [visual-direction.md](visual-direction.md)

**판정: 통과.** 방향은 맞다. 원래 기획안에는 재미를 결정하는 변수 여섯 개가 비어 있었고, 아래가 그 여섯 개에 대한 결정이다.

**한 줄 컨셉:** 주변의 모든 물건을 무기로 만들어 연쇄적인 사고와 파괴를 일으키는 Physics Action Roguelite.

**최종 판정 기준:** 방 하나에서 물건 하나를 던졌는데 예상보다 훨씬 큰 사고가 났을 때 "씨발 뭐야 ㅋㅋ 한 번 더 해봐야겠다"가 나오는가.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 시점 | 2D 탑다운, 고정 카메라, 한 화면. 그림은 3/4 기울임 |
| 자기 폭발 | 플레이어도 폭발 피해를 받는다. 예외 없음 |
| 당기기 | 업그레이드가 아니라 **기본 능력** |
| 투척 | 차징 없음. 첫 충돌까지 결정론적, 이후 물리 |
| 콤보 타이머 | 첫 접촉 이후에만 돈다 |
| 적 설계 | 1축은 물체로서의 성질, 2축이 공격 패턴 |
| 메타 진행 | 없음 |
| 런 길이 | 6~8분 (방 8개) |
| 점수 | 3종: Chain / Environment Kill / Overkill |
| 그래픽 | "도형이면 충분"이 아니다. 움직임과 사건 연출은 Phase 0부터 필수 |

## 치명적 구멍 6개와 해결

번호는 **파급력 순위**다. 01이 틀리면 02~06을 아무리 잘 해도 소용없다.

### 01 · 시점 → 2D 탑다운 (확정)

이 게임의 재미는 **내가 일으킨 사고를 끝까지 지켜보는 것**이다. 연쇄가 화면 밖에서 일어나면 재미는 0이다.

- 사이드뷰는 중력 때문에 연쇄가 아래로만 간다. 기름이 퍼지고 불이 옮겨가는 게 안 된다.
- 3D는 물리 예측이 어려워서 "내가 한 것"이라는 감각이 사라진다.
- 탑다운은 연쇄 전체가 한 화면에 들어오고, 평면 전파가 가장 잘 읽힌다.

### 02 · 탄약 고갈 → 세 겹으로 막는다

던지면 물건이 사라지고, 방이 비고, 맨손이 되면 루프가 무너진다. 이 장르에서 가장 흔한 실패 원인이다.

- 던진 물건은 부서지지 않는다(폭발물 제외).
- **당기기는 기본 능력이다.** 물건을 주우러 걸어다니는 시간은 전부 재미없는 시간이다.
- 적도 탄약이다(기절시키면 집을 수 있다).

### 03 · 플레이어의 죽음 → 자기 폭발로 죽는다 (확정)

위험이 정의되지 않으면 위험과 보상도 없다. **자기가 만든 폭발에 죽는 순간**이 이 게임에서 가장 좋은 학습 순간이다. "아, 저 거리에서 터뜨리면 안 되는구나"를 배우고, 다음 판에 위치를 잡는다. 이게 실력 향상의 유일한 경로다.

- HP는 3칸. 방어 수단은 대시 하나(무적). "터뜨리고 대시로 빠져나온다"가 스킬 천장이다.
- 사망 시 **사인을 표시한다**("사인: 네가 던진 가스통"). 억울함을 웃음으로 바꾼다.

### 04 · "예상 밖 결과"와 "내가 만든 결과"의 충돌 → 1타는 결정론적, 2타부터 물리

연쇄가 전부 예상 밖이면 도박이 되고, 전부 예측 가능하면 퍼즐이 된다.

- 던진 물체는 **첫 충돌까지 직선, 등속**으로 날아간다. 조준 가이드가 첫 충돌 지점을 보여준다.
- **폭발 반경은 항상 바닥에 보인다.** 가스통을 들고 있으면 조준 지점에 폭발 범위 미리보기가 뜬다.
- 첫 충돌 이후는 물리다. 플레이어는 1단계를 의도하고, 2단계부터는 선물로 받는다.

### 05 · 콤보 타이머가 관찰을 죽인다 → 첫 접촉 이후에만 돈다

이 게임의 좋은 순간은 방을 보며 "이걸 어떻게 조합하지?"라고 생각하는 3초다. 타이머가 처음부터 돌면 생각할 시간이 없다.

- 관찰은 무제한이다. 적도 처음에는 플레이어를 모른다.
- 첫 투척물이 맞는 순간부터 시계가 돈다. 관찰(느림)에서 실행(빠름)으로 가는 리듬이 생긴다.

### 06 · 적 설계 축이 거꾸로다 → 물체 성질이 먼저다

| 적 | 물체로서의 성질 | 플레이어가 하는 생각 | 등장 |
|---|---|---|---|
| 돌격병 | 기절시키면 탄약 | "기절시키고 가스통에 던지자" | Phase 0 |
| 폭발병 | 걸어다니는 가스통 | "쟤를 저기로 밀어야지" | Phase 1 |
| 거구 | 못 던짐. 밀면 벽을 뚫음 | "쟤를 벽 쪽으로" | Phase 4 |
| 금속 병사 | 자석, 전기에 반응 | "물에 넣고 감전" | Phase 4 |
| 기름짐 | 죽으면 바닥에 기름 | "먼저 죽이고 불을 붙인다" | Phase 4 |
| 드론 | 공중. 물건이 밑으로 지나감 | 위협 담당, 반드시 처리 | Phase 4 |

## 조정 권고

| 항목 | 변경 | 이유 |
|---|---|---|
| 런 길이 | 10~15분 → **6~8분** | 물리 액션은 인지 부하가 높다. 짧을수록 빠른 재시작의 가치가 커진다 |
| 점수 카테고리 | 7종 → **3종** | 사고가 터지는 0.5초 안에 읽혀야 한다 |
| 물체 종류 | 초기 **8종 이하** | 학습 대상은 물리 결과가 아니라 **물체의 규칙**이다. 규칙은 100% 일관돼야 한다 |
| 메타 진행 | **없음** | 영구 강화는 실력 성장을 가린다 |
| 던지기 | **차징 없음** | 세기 조절은 무게로 푼다 |
| 보스 | **Phase 5 이후** | 시스템 네 개가 완성돼야 성립한다 |

## 개발 일정 — Kill Gate 방식, 약 15주

각 페이즈 끝에 **Kill Gate**가 있다. 통과하지 못하면 다음 페이즈로 넘어가지 않는다.

| Phase | 내용 | 기간 | Kill Gate |
|---|---|---|---|
| **0** | 코어 검증: 방 1개, 물체 3종, 적 1종 → [phase0-spec.md](phase0-spec.md) | 1~2주 (최대 3주) | 처음 보는 5명 중 4명이 30초 안에 반응하는가 · 3명이 5분 이상 계속하는가 · 4명이 자기가 왜 죽었는지 말하는가 · GIF 테스트 |
| **1** | 연쇄를 시스템으로: 연쇄 추적, CHAIN ×N, 콤보 타이머, 전기+물, 물체 5종, 폭발병 | 2주 | 플레이어가 **의도적으로** 4연쇄를 노리는가. 실패하면 아쉬워하는가 |
| **2** | 런 구조: 방 8개, 방 선택 3분기, 사망→통계→AGAIN, 점수 3종 | 2주 | 자발적으로 3런 이상 연속 플레이하는가 |
| **3** | 빌드: 업그레이드 12개(전부 플레이 방식을 바꾸는 것, 스탯 상승 0개), 3택 1 | 2주 | 특정 업그레이드를 **노리고** 방을 고르는가 |
| **4** | 콘텐츠: 테마 3종(주방, 공장, 주유소), 테마별 고유 물체, 적 5~6종 | 3주 | 테마가 바뀌면 **플레이 방식**이 바뀌는가 |
| **5** | 보스 1종 + 폴리시 + 첫 방 튜토리얼 | 3주 | 보스를 **환경으로** 잡는가 |

### 일정 운영 원칙

1. **Phase 0에 시간을 아끼지 않는다.** 여기서 안 재밌으면 뒤에 뭘 붙여도 안 재밌다.
2. **매 페이즈 끝에 반드시 남에게 플레이시킨다.** 만든 사람은 조작법을 이미 알아서 진입장벽이 안 보인다.
3. **게이트에 실패하면 그 페이즈를 반복한다.** "나중에 고치자"는 없다.
4. **새 요소는 원래 기획안의 여섯 질문으로 거른다.** 대부분 "아니오"면 넣지 않는다.
5. **문제가 생기면 더하지 말고 뺀다.** "재미없다"의 원인은 거의 항상 부족이 아니라 과잉이다.

## 개발 AI 협업 규칙

개발 AI가 구현 가능 여부를 물으면 기획 AI는 다음 세 가지로 나눠 답한다.

- **필수:** 없으면 게임이 성립하지 않는다
- **권장:** 재미를 크게 키운다
- **보류:** 프로토타입 단계에서 뺀다

**구현 방법(엔진, 구조, 라이브러리)은 개발 AI가 정한다.** 기획 문서는 "무엇을, 왜, 플레이어가 무엇을 느껴야 하는지"를 정한다. 수치는 전부 시작값이고, 플레이테스트 결과로 바뀐다.

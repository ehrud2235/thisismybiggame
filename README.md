# thisismybiggame

> 기술 목록이 없는 MMA. 주먹 궤도를 플레이어가 직접 만들고, 상대는 주먹이 아니라 몸을 읽어서 막는다.

사람 대 사람 1대1, 리얼 시뮬레이션. UFC 5보다 빠른, 진짜 사람이 휘두르는 템포.

## 지금 단계

**Phase 0 — 서서 주먹만.** 선수 둘, 로컬 2인. 주먹 싸움이 재미로 검증되기 전에는 킥, 태클, 그라운드를 만들지 않는다.

## 역할

- **기획 AI:** 무엇을, 왜 만드는가. 재미 구조, 시스템, 밸런스, 수치 시작값
- **개발 AI:** 어떻게 만드는가. 엔진, 구조, 네트워크, 애니메이션 방식

기획 문서의 수치는 전부 시작값이다. 플레이테스트 결과에 따라 바뀐다.

## 판정 기준

상대가 못 본 주먹을 내가 만들어서 꽂았을 때, 옆 사람한테 **"야 방금 봤냐?"**가 나오는가.

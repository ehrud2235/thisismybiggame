# thisismybiggame

> 기술 목록이 없는 MMA. 주먹 궤도를 플레이어가 직접 만들고, 상대는 주먹이 아니라 몸을 읽어서 막는다.

사람 대 사람 1대1, 리얼 시뮬레이션. UFC 5보다 빠른, 진짜 사람이 휘두르는 템포.

## 지금 단계

**Phase 0 — 서서 주먹만.** 선수 둘, 로컬 2인. 플레이 가능한 프로토타입이 있다. 주먹 싸움이 재미로 검증되기 전에는 킥, 태클, 그라운드를 만들지 않는다.

## 실행

Node만 있으면 된다. 설치할 패키지는 없다.

```
npm start
```

브라우저에서 http://localhost:8080 을 연다.

- **P1:** 키보드·마우스, 또는 첫 번째 게임패드
- **P2:** 두 번째 게임패드. 없으면 스파링 봇 (`B`로 봇 / 샌드백 / 패드 전환)
- `` ` ``: 디버그 패널 (수치 실시간 조정, 로그 저장) · `T`: 주먹 궤도 표시

GitHub Pages를 켜면(Settings → Pages → `main` / root) 설치 없이 링크로 플레이할 수 있다.

## 테스트

```
npm test
```

봇 대 봇으로 30판을 돌려서 결정성(같은 입력이면 같은 결과), NaN, 평균 경기 시간, 적중률, 다운 빈도를 출력한다. 렌더 없이 Node에서 돈다.

`tools/browsertest.mjs`는 Playwright로 실제 브라우저에서 경기, 리플레이, 종료 화면까지 돌려보고 콘솔 에러를 확인한다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/config.js` | 모든 튜닝 값과 몸 치수 |
| `src/math.js` | 시뮬 전용 벡터 연산, IK |
| `src/fighter.js` | 선수 한 명: 궤도 생성, 방어, 균형, 스태미나, 다운 |
| `src/combat.js` | 타격 판정, 못 본 주먹, 데미지 배율 |
| `src/sim.js` | 경기: 고정 60틱, 입력 두 개로만 진행 |
| `src/input.js` | 게임패드, 키보드·마우스 → 입력 상태 |
| `src/bot.js` | 스파링 봇 |
| `src/render.js` | three.js 렌더링. 시뮬 스냅샷만 받아서 그린다 |
| `src/audio.js` | 효과음 (WebAudio 합성) |
| `src/main.js` | 루프, 리플레이, HUD, 디버그 패널 |

**시뮬은 렌더와 완전히 분리돼 있고 난수를 쓰지 않는다.** 같은 입력이면 같은 결과가 나온다. 온라인 대전(롤백)을 붙일 때의 전제다.

## 역할

- **기획 AI:** 무엇을, 왜 만드는가. 재미 구조, 시스템, 밸런스, 수치 시작값
- **개발 AI:** 어떻게 만드는가. 엔진, 구조, 네트워크, 애니메이션 방식

기획 문서의 수치는 전부 시작값이다. 플레이테스트 결과에 따라 바뀐다.

## 판정 기준

상대가 못 본 주먹을 내가 만들어서 꽂았을 때, 옆 사람한테 **"야 방금 봤냐?"**가 나오는가.
